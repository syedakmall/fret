# Fret

A retro pixel-art visual tool for guitar and bass players to explore scales, modes, chord voicings, and progressions across the neck. Built with Next.js and Tailwind CSS.

## Features
- **Interactive Fretboard**: See exactly where notes land across the entire neck.
- **Custom Tunings**: Standard, Drop D, DADGAD, and more.
- **Multiple Woods**: Rosewood, Maple, and Ebony fretboards.
- **Practice Mode**: A built-in sequencer to play through chords and scales.

## Development

```bash
npm install
npm run dev
```
